# LISA: простая схема модели по умолчанию

Памятка к [nn_modules.py](../../code/LISA/src/lisa/model/nn_modules.py).
Здесь показаны настройки default-запуска из
[parse_experiment_args.py](../../code/LISA/src/lisa/cli/parse_experiment_args.py),
а не все возможные варианты модели.

**B** — число примеров в батче. **T** — число отсчётов времени.
Для наглядности ниже взято **T = 300**: 3 секунды MEG при 100 Гц.

## Путь данных

```text
meg: (B, 208, 300) + subject_idx: (B,)
 │
 ▼
SpatialModule
 ├─ 3D-внимание                  → (B, 270, 300)
 ├─ Общая матрица unmixing        → (B, 270, 300)
 ├─ Индивидуальная матрица        → (B, 25, 300)
 └─ Временной фильтр             → (B, 25, 300) = z, или Z1
 │
 ▼
TemporalModule
 ├─ Первый ConvBlock             → (B, 25, 300)
 └─ Второй ConvBlock             → (B, 25, 300)
 │
 ▼
ConvHead
 └─ GELU → Conv1d → BatchNorm     → (B, 768, 149) = y
```

Модель возвращает **пару `(z, y)`**. `z` — промежуточные пространственные
каналы после фильтрации; `y` — последовательность признаков для сравнения с аудио.

## Как классы связаны между собой

```text
LISA                              собирает всю MEG-модель
 ├─ spatial_module: SpatialModule
 │   ├─ self_attention: Spatial3DAttentionLayer
 │   ├─ unmixing_layer: nn.Conv1d
 │   ├─ subject_layer: SubjectPlusLayer
 │   └─ temporal_filter: nn.Conv1d
 ├─ temporal_module: TemporalModule
 │   └─ conv_blocks: два ConvBlock
 └─ feature_projection: ConvHead
```

**Это вложенные объекты, а не порядок объявления классов в файле.**
Порядок вычислений задаёт `forward`, а `__init__` создаёт нужные слои и параметры.

`Spatial3DAttentionLayer` наследуется от `SpatialAttentionLayerBase`:
базовый класс содержит общий `forward`, а 3D-класс объясняет, как построить
матрицу из сферических гармоник. Поэтому `_get_attention_matrix` с
`raise NotImplementedError` в базовом классе — заготовка. У 3D-класса есть
работающая версия этого метода.

## Что происходит внутри основных частей

| Часть | Простое объяснение | Что обучается |
|---|---|---|
| 3D-внимание | Смешивает датчики в 270 каналов с учётом их расположения | Коэффициенты `Z` сферических гармоник; координаты и базис фиксированы |
| Unmixing | Ещё раз смешивает 270 каналов общей для всех матрицей | Матрица `270 → 270` и смещение |
| Subject layer | Выбирает преобразование для конкретного участника | У каждого из 27 участников своя матрица `270 → 25` |
| Временной фильтр | Обрабатывает соседние моменты отдельно в каждом канале | 25 ядер длины 15 отсчётов, со случайной инициализацией |
| Два ConvBlock | Совместно обрабатывают каналы и временные закономерности | Свёртки и параметры BatchNorm |
| ConvHead | Переводит 25 каналов в 768 признаков и сокращает время | Свёртка с ядром 3 и шагом 2, параметры BatchNorm |

Внимание использует размер базиса **24 × 24**, то есть 576 гармоник на
выходной канал. Это другой параметр, чем **25 каналов** после subject layer.

Один **ConvBlock** внутри устроен так:

```text
Conv1d 25→25 → [прибавить вход только во втором блоке] → BatchNorm → GELU
    ↓
Conv1d 25→25 → прибавить вход этой свёртки → BatchNorm → GELU
    ↓
Conv1d 25→50 → GLU 50→25
```

Прибавления — остаточные связи: сигнал идёт и через свёртку, и напрямую.
GLU делит 50 каналов пополам и вычисляет `первая_половина * sigmoid(вторая_половина)`.
Все эти свёртки сохраняют длину времени. Только голова сокращает 300 до 149.

В VS Code можно искать через **⌘T** имена классов из дерева, затем смотреть
их `forward`. Начать удобнее с `LISA`, потом `SpatialModule`, `ConvBlock`, `ConvHead`.

## Что пока можно пропустить

- `Spatial2DAttentionLayer` — альтернативное 2D-внимание; default использует 3D.
- `FiltFiltConv1d` — фильтр с проходом вперёд и назад; default использует обычный `conv`.
- `AdditiveAttentionPooling`, `GatedAttentionPooling`, `QueryAttentionPooling`,
  `TimeReduction` — дополнительные способы сжатия времени; default их не включает.
- `AudioEmbeddingModel` — отдельный адаптер уже готовых аудиопризнаков;
  в default-конфигурации загрузчик использует вместо него `Identity`.
- Spatial dropout, FIR-инициализация по полосам, gate и GELU внутри `SpatialModule`
  выключены. GELU и GLU внутри временных блоков, а также GELU в голове работают.
- `extract_spatial_filters` и `extract_temporal_filters` — достают веса для анализа,
  не являются шагами обычного прямого прохода.

Вспомогательные функции: `get_spatial_attention_layer` выбирает класс внимания,
`cart2sph` переводит координаты датчиков в сферические. Это подготовка модели.

## Где начинается обучение

```text
cli/train_model.py: main()
  → train(): создаёт данные, модель и Trainer
    → training/trainer.py: Trainer.fit()
      → предсказание → loss → backward() → optimizer.step()
```

[Запуск обучения](../../code/LISA/src/lisa/cli/train_model.py) и
[цикл обучения](../../code/LISA/src/lisa/training/trainer.py) находятся в других файлах.
`nn_modules.py` задаёт слои и вычисления модели; обновление весов делает Trainer.

**Место идеи exp10:** общую матрицу можно добавить рядом с индивидуальными
в `SubjectPlusLayer`, на переходе **270 → 25**, перед временным фильтром.
Это предложение для эксперимента; в исходной схеме такой матрицы нет.

Примечание к текущей локальной копии: в `ConvHead` написано `kernel_sie=3`
вместо `kernel_size=3`. Эта опечатка мешает создать default-голову;
выше описана схема с предполагаемым ядром 3. Исходный код этой памяткой не изменён.

# Эксперименты

Каждый опыт собран в отдельной папке. Его номер совпадает с номером в [каталоге скриптов](../code/scripts/README.md).

Статусы сверены **30.10.2026** по сохранённым материалам. Последние результаты полной серии — 17–19 октября.
[Текущие задачи](../docs/plan.md) связывают эксперименты с договорённостями встреч; [исследования](../docs/research/README.md) содержат открытые вопросы и литературу.

## Устройство папки

```text
expNN_name/
├── README.md       # постановка, ход работы, результаты и команды
├── protocol.json   # машиночитаемый протокол, если он уже есть
└── results/        # небольшие таблицы, отчёты проверок и рисунки
```

В README каждого опыта обязательны разделы **«Гипотеза»**, **«Задачи»** и **«Скрипты»**. Гипотеза задаёт проверяемое ожидание и сравниваемые условия; задачи описывают шаги проверки; скрипты перечисляются с путями от корня репозитория и назначением. Для технических проверок указывается техническое ожидание, для нереализованных планов — отсутствие отдельного скрипта и связанные реализации.

Разделы добавлены при упорядочивании документации по уже описанным вопросам и протоколам. Для завершённых опытов это ретроспективная формулировка, а не новая предварительная регистрация. Исходные даты, протоколы, результаты и ограничения сохранены; наличие гипотезы не означает её подтверждение.

Папки и файлы создаются по мере готовности опыта. Exp01/exp02 — исторические планы: связанные проверки реализованы в последующих опытах с собственными условиями. У exp07 есть протокол и код, но подтверждённых результатов серии в репозитории пока нет.

## Данные и воспроизводимость

Сырые данные, подготовленные массивы, checkpoint и полные обучающие прогоны хранятся в `data/` и `outputs/` согласно `.gitignore`. В `results/` каждого опыта лежат небольшие артефакты для анализа и отчёта.

Результаты исходных прогонов перенесены без изменения содержимого. Записанные внутри них прежние пути остаются историческими метаданными. Протоколы exp04–exp06 сохранены с прежними SHA-256, чтобы проверки подготовленных данных и checkpoint продолжали работать. В протоколе exp07 обновлён только путь к отчёту подготовки exp06.

Общие результаты exp08/exp09 не дублируются: `exp08_09_full_lisa/results/full_raw/` содержит таблицы обоих опытов. Контроль на 22 участниках хранится отдельно в `exp08_matched22/results/`.

При добавлении опыта создавайте папку `expNN_name/`, отчёт `README.md` и соответствующую папку кода. Научные параметры фиксируйте в протоколе; для новой несовместимой серии сохраняйте отдельный каталог результатов. Числа и статусы в старых отчётах отражают дату описанного запуска.

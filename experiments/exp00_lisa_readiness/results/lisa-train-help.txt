Training a MEG retrieval model

options:
  -h, --help            show this help message and exit
  --device DEVICE       Device to use: 'cpu' or 'cuda[:N]'.
  --batch-size BATCH_SIZE
                        Training batch size.
  --test-batch-size TEST_BATCH_SIZE
                        Test/validation batch size. Default: 20.
  --meg-sr MEG_SR
  --meg-offset MEG_OFFSET
  --val-story-sounds VAL_STORY_SOUNDS
                        Validation story/sound pairs held out from train,
                        formatted as
                        "story_id:sound_id[,story_id:sound_id...]". Default:
                        "3:4".
  --dirprocess DIRPROCESS
                        Root directory with preprocessed embeddings/metadata.
  --meg-files-dir MEG_FILES_DIR
                        Root directory of MEG files (clean or raw).
  --meg-format {bids,fif}
                        MEG file format: fif (clean) or bids (raw MASC-MEG).
  --embedding-layers EMBEDDING_LAYERS
                        Number of Wav2Vec2 layers used in embeddings (must
                        match files generated by lisa-generate-embeddings).
                        Default: 4 (used in paper).
  --window-tag WINDOW_TAG
                        Segment-length ablation tag selecting alternative
                        embeddings/dataframe files produced by lisa-regen-
                        windows (e.g. "w5"). Empty (default) uses the
                        canonical 3-second files, so runs are identical to the
                        baseline. When set, training loads
                        extract_features_{split}{layers}_{tag}.npy and
                        df_{split}{N}_{tag}.csv from the same --dirprocess
                        (MEG npz is shared).
  --feature-reduction {none,pca,linear}
                        Feature-axis reduction mode. PCA is audio-only
                        preprocessing; linear keeps audio/MEG trainable.
  --feature-reduction-dim FEATURE_REDUCTION_DIM
                        Reduced feature dimension for --feature-reduction.
                        Required unless --feature-reduction=none.
  --time-reduction {none,pca,linear,mean,max,adaptive_avg,adaptive_max,attn,gated_attn,query_attn}
                        Time-axis reduction mode. PCA is audio-only
                        preprocessing; all other modes use the same in-model
                        time-reduction module on audio and/or MEG as
                        appropriate.
  --time-reduction-dim TIME_REDUCTION_DIM
                        Reduced/output time length for --time-reduction.
                        Required for pca, linear, adaptive pooling, and query
                        attention.
  --time-reduction-hidden-dim TIME_REDUCTION_HIDDEN_DIM
                        Hidden size for attention-style time reduction (attn,
                        gated_attn).
  --time-reduction-num-heads TIME_REDUCTION_NUM_HEADS
                        Number of heads for query-attention time reduction.
  --n-channels-attention N_CHANNELS_ATTENTION
  --n-channels-unmix N_CHANNELS_UNMIX
  --use-spatial-attention {2D,3D,none}
                        Type of spatial attention: 2D (Fourier), 3D (spherical
                        harmonics), or none (disabled).
  --use-unmixing-layer, --no-use-unmixing-layer
                        Enable the 1x1 unmixing layer inside the spatial
                        module.
  --use-subject-layer, --no-use-subject-layer
                        Enable the subject-specific layer inside the spatial
                        module.
  --n-spatial-harmonics N_SPATIAL_HARMONICS
  --spatial-dropout-number SPATIAL_DROPOUT_NUMBER
                        Number of spatial dropout centers (0 to disable).
  --spatial-dropout-radius SPATIAL_DROPOUT_RADIUS
                        Radius for spatial dropout.
  --dropout-center-low DROPOUT_CENTER_LOW
                        Lower bound for spatial dropout center sampling range
                        in coords_xy space.
  --dropout-center-high DROPOUT_CENTER_HIGH
                        Upper bound for spatial dropout center sampling range
                        in coords_xy space.
  --temporal-filter-type {conv,filtfilt}
                        Type of temporal filter: conv or filtfilt (zero-
                        phase).
  --temporal-filter-padding-mode {zeros,reflect,replicate,circular}
                        Padding mode for temporal filter.
  --temporal-filter-bands TEMPORAL_FILTER_BANDS
                        Frequency bands for FIR initialization (Hz). If None,
                        no FIR initialization. Format: low1-high1,low2-high2
  --temporal-filter-freeze, --no-temporal-filter-freeze
                        Freeze temporal filter weights after initialization.
  --temporal-filter-kernel-size TEMPORAL_FILTER_KERNEL_SIZE
                        Kernel size of temporal filter in samples.
  --tf-gated, --no-tf-gated
                        Enable residual gate: y = x + sigmoid(gamma) *
                        (Conv(x) - x)
  --tf-gate-per-channel, --no-tf-gate-per-channel
                        Learn per-channel gate (gamma vector) instead of
                        scalar.
  --tf-gate-init-alpha TF_GATE_INIT_ALPHA
                        Initial alpha for temporal gate (in [0,1]).
  --tf-gelu, --no-tf-gelu
                        Enable GELU activation after temporal filtering in
                        spatial module.
  --n-channels-block N_CHANNELS_BLOCK
                        Number of channels in temporal conv blocks, or 'auto'
                        to match --n-channels-unmix.
  --n-temporal-module-blocks N_TEMPORAL_MODULE_BLOCKS
                        Number of temporal conv blocks (0 for no temporal
                        module).
  --head-pool {conv,single_conv}
                        Pooling type for projection head.
  --head-stride HEAD_STRIDE
  --seed SEED           Random seed, or 'none' for an unseeded run.
  --torch-deterministic, --no-torch-deterministic
                        Use deterministic CUDA/cuDNN (reproducible; slower).
                        Default: False (faster convs).
  --dl-n-workers DL_N_WORKERS
  --lr-fe LR_FE
  --optim {Adam,AdamW}  Optimizer type.
  --weight-decay WEIGHT_DECAY
  --clip-temperature CLIP_TEMPERATURE
  --clip-temperature-lr CLIP_TEMPERATURE_LR
  --nepoch NEPOCH
  --early-stopping-patience EARLY_STOPPING_PATIENCE
                        Stop after this many consecutive epochs without
                        validation-loss improvement (strict improvement =
                        lower loss than the running best). Use 'none' to
                        disable and train for the full --nepoch.
  --tf-unfreeze-epoch TF_UNFREEZE_EPOCH
                        Epoch to start training temporal filters (None =
                        always train).
  --lr-temporal-mult LR_TEMPORAL_MULT
                        Learning rate multiplier for temporal filter.
  --wd-temporal WD_TEMPORAL
                        Weight decay for temporal filter (None = use main
                        weight-decay).
  --tf-smooth TF_SMOOTH
                        Smoothness penalty (L2 of second difference) for
                        temporal filter kernel.
  --logging-project LOGGING_PROJECT
  --run-group RUN_GROUP
                        Run group id for grouping runs (e.g. 5conv-10ch).
                        Stored in config; experiment dir is
                        experiments/<run_group>/<run_name>_<run_id>/.
  --max-branches-to-plot MAX_BRANCHES_TO_PLOT
                        Maximum branches to show on filter plots.
  --plot-filter-graphs, --no-plot-filter-graphs
                        Plot and save temporal/spatial filter graphs after
                        each epoch. Disabled by default; spatial graphs
                        require source MEG FIF/BIDS files.
  --experiments-root EXPERIMENTS_ROOT
                        Root directory to save experiment data.
  --image-formats IMAGE_FORMATS [IMAGE_FORMATS ...]
  --upload-metrics-csv, --no-upload-metrics-csv
                        Upload metrics.csv as ClearML artifact.
  --log-images-to-server, --no-log-images-to-server
                        Upload figures (temporal/spatial filters) to server
                        (only works if non-local logging is used). Default:
                        False.
  --logger {clearml,local}
                        Experiment logger: local (save to disk only; default)
                        or clearml (requires pip install lisa[clearml]).
  --save-test-top-k SAVE_TEST_TOP_K
                        Number of top retrieval predictions per test window to
                        dump to final_test_per_window.npz alongside
                        metrics.csv. rank_of_true is always saved separately
                        and covers any post-hoc Top-K accuracy.

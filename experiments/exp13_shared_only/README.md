# Эксперимент 13 — одна общая матрица LISA

**Статус** — подготовлены протокол и скрипт запуска для шести обучений `shared_only`.

## Гипотеза

Если пропускать все обучающие окна через одну общую матрицу, LISA будет лучше искать аудио для новых участников, чем при маршрутизации 90/10 из exp12. В `shared_only` матрица получает градиент через каждое окно обучения, и эта же матрица применяется на валидации и тесте.

В завершённой серии exp12 `full_4pergpu_20ep_20261123_141324` тестовый Top-10 составил 35,41% у маршрутизации 90/10 и 34,11% у арифметического среднего личных матриц. В пятиэпоховом пилоте exp10 на отдельной тройке участников `shared_only` дал 39,09% против 36,92% у 90/10. Exp13 проверяет эту разницу на всех шести фолдах exp12. [Пилот exp10](../exp10_shared_matrix/README.md#предварительные-результаты-clean-пилота-05112026)

## Задачи

1. Сохранить разбиение по участникам и аудио, подготовленные данные и настройки завершённой серии exp12.
2. Обучить `shared_only` на каждом из шести фолдов и выбрать чекпойнт по валидационным участникам.
3. Сравнить тестовый Top-10 попарно по людям с `switch_p0p9` и `individual` из exp12. Для промежуточной сводки указать завершённые фолды и число участников.

## Протокол

| Условие | Матрица при обучении | Матрица на валидации и тесте |
|---|---|---|
| `shared_only` | Общая для 100% окон | Обученная общая |
| `switch_p0p9` из exp12 | Личная для 90%, общая для 10% окон | Обученная общая |
| `individual` из exp12 | Личная для 100% окон | Среднее 18 обученных личных матриц |

Разбиение взято из exp12. В каждом фолде 18 обучающих участников, 4 или 5 валидационных и 5 или 4 тестовых. Используются обе доступные сессии. Лимит обучения — 20 эпох, сид — `42`, AdamW с `lr=3e-4`, размер батча — `100`. Чекпойнт выбирается по среднему Top-10 на валидационных участниках с равным весом людей. При равенстве сравнивается Top-1, затем выбирается более ранняя эпоха. [Машиночитаемый протокол](protocol.json) · [Разбиение и данные exp12](../exp12_paired_shared_matrix/README.md)

На валидации используется банк из 108 аудиокандидатов, на тесте — из 1005. Бюджет размеченной калибровки составляет 0 окон. Сохраняется исходная поканальная нормировка по неразмеченной целевой записи.

Основная метрика — разность тестового Top-10 `shared_only − switch_p0p9` в процентных пунктах. Дополнительное сравнение — `shared_only − individual`. Для каждого человека сначала усредняются его окна по всем доступным сессиям, затем парные разности усредняются с равным весом людей. Сопоставляются строки `eval/<задача>/subjects.csv` по фолду, сиду и `subject_id` с оценками завершённой серии exp12. Сохраняются также Top-1 и средний ранг.

### Запуск на кластере ВШЭ

Выполните команды из корня репозитория в окружении LISA, использованном для exp12.

```bash
CANON=/home/isemenkov/shared-datasets/LISA/preprocessed
OUT=outputs/exp13_shared_only
mkdir -p "$OUT/logs"
sbatch --output="$OUT/logs/%A_%a.log" \
  experiments/exp13_shared_only/scripts/run_hse.sbatch "$CANON" "$OUT"
```

По умолчанию Slurm запускает шесть фолдов, до двух одновременно. Для запуска только фолда 0 добавьте `--array=0` перед путём к скрипту. Каждый фолд обучается по протоколу exp13, затем лучший чекпойнт оценивается на тестовой выборке. Метрики по участникам сохраняются в `$OUT/eval/<задача>/subjects.csv`.

### Запуск на выделенном GPU

Раннер поддерживает все три указанных в протоколе варианта. В exp13 запускаются шесть заданий `shared_only` по имени. Команды для первого фолда выполняются из корня репозитория на выделенном GPU. Для остальных фолдов меняется имя задачи на `shared_only_f1_s42` … `shared_only_f5_s42`.

```bash
RUNNER=code/scripts/exp10_shared_matrix/run_experiment.py
PROTOCOL=experiments/exp13_shared_only/protocol.json
CANON=/home/isemenkov/shared-datasets/LISA/preprocessed
OUT=outputs/exp13_shared_only
TASK=shared_only_f0_s42
export CUBLAS_WORKSPACE_CONFIG=:4096:8

.venv/bin/python "$RUNNER" tasks --protocol "$PROTOCOL" --task "$TASK"
.venv/bin/python "$RUNNER" train --protocol "$PROTOCOL" --task "$TASK" --canon "$CANON" --out "$OUT" --threads 4
.venv/bin/python "$RUNNER" eval --protocol "$PROTOCOL" --task "$TASK" --canon "$CANON" --out "$OUT" --threads 4
```

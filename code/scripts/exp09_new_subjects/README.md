| Скрипт | Задача |
|---|---|
| [eval_mean_seen.py](eval_mean_seen.py) | Дополнительная оценка средней матрицы на тех же 18 участниках, уже включённых в обучение модели воспроизведения. |

Команды выполняются из корня репозитория по полному пути `code/scripts/exp09_new_subjects/имя_скрипта.py`. Общие правила и проверки — в [каталоге скриптов](../README.md).

Основная серия новых участников запускается через [общий полный пайплайн](../exp08_09_full_lisa/README.md). Этот дополнительный скрипт измеряет среднюю матрицу на уже виденных участниках и не является оценкой zero-shot переноса на новых людей.

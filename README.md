# ВКР — Методы межсубъектной генерализации и адаптации при декодировании воспринимаемой речи по МЭГ

Научный трек, 2026–2027. Научный руководитель: И. Семёнков (AIRI / ВШЭ).

**Задача.** Декодер LISA хранит для каждого обучающего участника отдельную
обучаемую пространственную матрицу Wₛ (`SubjectPlusLayer`). Для нового человека
такой матрицы нет. Работа исследует перенос декодера на нового человека при
ограниченном бюджете калибровки, в том числе без дообучения весов сети.
Качество оценивается поиском соответствующего аудиоокна среди фиксированных кандидатов.

## Текущее состояние

Обновлено **30 октября 2026 года** по сохранённым отчётам и договорённостям.
Последние результаты полной серии относятся к 17–19 октября; обновление документации не означает новый запуск.

- Выполнены пилоты и LOSO-калибровка на 27 участниках (exp00, exp03–exp06).
- В полной серии exp08 качество выбранной авторской конфигурации попало в заданный допуск. Серия выполнена на **raw без ICA**, поэтому это не точное воспроизведение предобработки статьи.
- Проверен перенос между сессиями в обоих направлениях, включая контроль на одинаковых 22 участниках.
- Для новых людей получен baseline со средней Wₛ: exp09 выполнен на **6 из 9 фолдов, 18 участниках**.
- Ближайшая методическая задача — валидация на отдельных новых людях и вывод validation-метрик рядом с test. В сохранённом exp09 checkpoint выбирается по знакомым людям.

## Основные результаты

| Проверка | Результат | Условия и источник |
|---|---|---|
| Калибровка нового человека дообучением Wₛ | Top-10 **59,8% при 30 с**, **80,3% при 882 с** | [exp06](experiments/exp06_loso/README.md): 24 оцениваемых человека × 3 сида, 99 кандидатов, одна сессия и две истории |
| Перенос своей Wₛ между сессиями | Top-10 **65,8 → 46,4%** (0 → 1) и **67,2 → 33,6%** (1 → 0) | [exp08 matched22](experiments/exp08_matched22/README.md): одинаковые 22 человека, 3 сида, 1005 кандидатов |
| Средняя Wₛ на новых людях | Top-10 **35,4%** против **70,5%** с собственной обученной Wₛ | [exp09](experiments/exp09_new_subjects/README.md): 18 человек, один сид на фолд, 1005 кандидатов; у референса человек был в обучении |

Проценты exp06 и полной серии напрямую не сравниваются: различаются данные и банк кандидатов.
В matched22 падение при смене сессии подтверждено в обоих направлениях, а различие величин падения после поправки Холма — нет.
В полной серии нормировка использует неразмеченные данные целевой записи; это нужно учитывать при оценке переноса без калибровки.
Доверительные интервалы, статистика и ограничения приведены в отчётах экспериментов.

## Окружение и запуск

Python 3.11, PyTorch 2.6.0; зависимости зафиксированы в `pyproject.toml` и `uv.lock`.
Перед установкой нужен checkout `code/LISA/` версии для выбранного эксперимента; он подключается как editable-пакет.
Для полной серии:

```bash
git clone https://github.com/ivsemenkov/LISA.git code/LISA
git -C code/LISA checkout ff9412e193a3877d07a27b644eb8a2575d357a32
uv sync --frozen
```

Локальные проверки без скачивания нейроданных:

```bash
.venv/bin/python code/scripts/exp00_lisa_readiness/smoke_lisa.py --output /tmp/fqw_lisa_smoke.json
.venv/bin/python -m pytest tests
```

Синтетический smoke проверяет вычисления, а не качество декодирования.
CLI `lisa-train` поддерживает CPU и CUDA; MPS через этот CLI не поддерживается.
Полные серии выполнялись на GPU Vast.ai. Подготовка данных, серверное окружение и команды — в [отчёте exp08](experiments/exp08_cross_session/README.md) и [контроле matched22](experiments/exp08_matched22/README.md).
На локальном macOS ARM64 при последней проверке не загружался бинарный модуль SciPy; сквозной тест и пересчёт статистики требуют исправного окружения (см. локальные ограничения в отчёте matched22).

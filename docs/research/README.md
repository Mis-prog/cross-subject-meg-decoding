## Открытые вопросы и возможные проверки

Направления обсуждены на [встрече 19 октября](../meetings/2026-10-19_semenkov_outcomes.md), кроме отдельно обозначенного резерва.
Ниже указаны рабочие способы проверки; это предложения по реализации, а не уже утверждённые протоколы.

| Вопрос | Что уже есть | Следующая проверка / результат ресерча |
|---|---|---|
| Как выбирать модель для переноса на нового человека? | Замечание к validation в [exp09](../../experiments/exp09_new_subjects/README.md), [обзор оценки](2026-10-07_cross_subject_transfer_review/topics/05_evaluation.md) | Задать train/val/test по людям и сравнить выбор checkpoint по новым и знакомым людям; публиковать validation рядом с test |
| Лучше ли обучаемая общая Wₛ арифметического среднего? | Средняя в exp09 и идея N+1-й матрицы из встречи; [обзор subject-слоёв](2026-10-07_cross_subject_transfer_review/topics/03_subject_layers_peft.md) | Уточнить маршрутизацию и подбор p; сравнить на одном разбиении с обычной средней |
| Какое ковариационное выравнивание подходит LISA? | [Разбор alignment](2026-10-07_cross_subject_transfer_review/topics/02_alignment.md); предварительный EA ухудшал качество в собственном протоколе exp06 | Разобрать EA/RA и выбрать референс; сначала проверить межсессионный перенос полной серии с явным объёмом целевых данных |
| Какие методы используют общий стимул для функционального выравнивания? | [Обзор alignment](2026-10-07_cross_subject_transfer_review/topics/02_alignment.md), [подготовленные align-методы exp07](../../experiments/exp07_frozen_calibration/README.md) | Выбрать несколько первичных работ, выписать требования к синхронности и общим стимулам; сформулировать проверку на отложенных окнах |
| Поможет ли обучение представлений, инвариантных к человеку? | Идея adversarial-головы из встречи, [общий обзор переноса](2026-10-07_cross_subject_transfer_review.md) | Разобрать подходящие методы и ограничения оси «сессия»; предложить голову по человеку и схему валидации |
| Можно ли использовать готовую ЭЭГ/МЭГ-модель? | [Обзор предобучения и адаптации](2026-10-07_cross_subject_transfer_review/topics/04_foundation_tta.md); на встрече названы CBraMod и REVE | Обновить обзор первичных источников, проверить типы датчиков, координаты, частоты и лицензию весов; выбрать один применимый baseline |
| Меняется ли перенос при другом аудиоэнкодере или новой истории? | Опциональные WavLM и leave-one-story-out из встречи | Отдельные протоколы: для энкодера сохранить банк/разбиение, для историй учитывать разный размер и состав банков |
| Можно ли выбирать похожих доноров вместо среднего всех? | Поддержано [5 октября](../meetings/2026-10-05_semenkov_outcomes.md); выбор Wₛ подготовлен в exp07 | Резерв: определить признаки сходства, доступный бюджет и validation; сравнить с фиксированной средней |

## Как вести новое направление

Для нового вопроса создаём заметку `YYYY-MM-DD_topic.md`: вопрос и связь с ВКР, первичные источники, что из них следует и что остаётся гипотезой, возможная проверка и ограничения.
Добавляем ссылку в карту выше. Когда появляется конкретный запуск, создаём эксперимент с гипотезой, протоколом и ссылкой на исходную заметку; после запуска добавляем обратную ссылку на результат.
Отрицательные результаты и причины отказа от метода сохраняем вместе с условиями проверки.
Номер нового эксперимента назначаем при подготовке его протокола.

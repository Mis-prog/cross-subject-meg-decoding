Перенос LISA на нового человека без дообучения нейросети

Исследовательский обзор для FQW · 24 сентября 2026

Вопрос: какие способы калибровки позволяют использовать уже обученную LISA на новом человеке, не выполняя градиентное дообучение её весов? Как использовать геометрию головы и короткий известный аудиостимул?

Это обзор первичных работ и аудит локального проекта, а не новые экспериментальные результаты. Числа из exp06 ниже относятся к уже проведённым опытам. Предлагаемые варианты для LISA помечены как гипотезы. Обзор охватывает основные подходящие семейства, но не претендует на исчерпывающий систематический поиск всей литературы.

1. Решение, к которому приводит обзор

Для этой ВКР наиболее продуктивна постановка «калибровка замороженного МЭГ-декодера по короткой записи нового участника». Внутри неё стоит разделить режимы с неизвестным и известным аудио.

Первая серия должна проверить четыре причины плохого переноса: неправильный масштаб, неудачный выбор субъектной матрицы, сдвиг статистик внутри сети и несогласованность пространственных компонентов. Это даёт понятную последовательность: исправленный baseline → выбор/ансамбль готовых субъектных слоёв → AdaBN → выравнивание по общему стимулу. Геометрию лучше сначала использовать как диагностический признак и prior для выбора, а физическое преобразование измерений оставить отдельной более сложной веткой.

Главный кандидат на содержательный результат ВКР: небольшой внешний калибратор, вычисляемый по общему аудиофрагменту и приводящий ответ нового человека к фиксированному пространству ветвей обученной LISA. Проверять его нужно вместе с более простыми альтернативами, иначе выигрыш может оказаться следствием исправления масштаба.

Самый дешёвый дополнительный эксперимент: выбирать уже существующую W_s по короткой записи с известным аудио или усреднять предсказания нескольких W_s. Это не то же самое, что усреднять сами матрицы.

Самая важная новая альтернатива относительно exp06: AdaBN — оценка статистик BatchNorm по калибровочному МЭГ при фиксированных обученных параметрах. В exp06 статистики BatchNorm были заморожены.

2. Что именно означает «без обучения»

Режим Что разрешено для нового участника Как корректно называть
A Ничего подбирать; только запуск заранее фиксированного алгоритма Zero-shot по участнику, без индивидуального fitting
B Оценить средние, дисперсии, ковариации, геометрию Калибровка по статистикам без градиентов
C По известному стимулу выбрать готовый слой, лаг, вычислить Procrustes/ridge Калибровка с известным стимулом без градиентного дообучения
D Подбирать новую W_s оптимизатором Дообучение; это уже проверенный сравнительный ориентир
E Заново обучить общую модель на source-людях, затем не обучать на новом Изменение source-training для переноса без target-finetuning

Решение ridge одной формулой всё равно является статистическим обучением внешнего преобразования. Обновление BatchNorm меняет состояние модели, хотя не меняет обученные gamma/beta и свёрточные веса. Подбор готовой W_s меняет выбор функции. Поэтому полезнее фиксировать три признака: есть ли target labels, меняются ли параметры нейросети, используется ли градиент.

Известное аудио уже задаёт пары МЭГ–стимул. Оно не требует ручной разметки, но такой режим нельзя называть label-free. Zero-shot по новому аудиофрагменту также не тождествен zero-shot по новому человеку; это различие существенно при чтении работ по speech retrieval. Défossez et al., 2023.

3. Что уже есть в FQW

Проверены протокол exp06, отчёт, обучение и калибровка, подготовка и слои LISA.

Проведённые опыты

  • 27 участников; 3 dev-участника; итоговая оценка на 24 людях × 3 seed.
  • 294 train, 76 validation, 99 test-окон на человека. Окна по 3 секунды без перекрытия: это проверено в prepare_mini_loso.py, а не перенесено из схемы окон оригинальной статьи.
  • Две истории, одна сессия; банк из 99 тестовых аудиофрагментов. Это не проверка на полностью новой истории.
  • Общая модель обучается без отложенного человека. shared_ea обучалась с EA и на source-участниках: её провал нельзя объяснять только внезапным применением EA на тесте.
  • Основная нормировка target подбирается только по бюджету; pool_* — отдельный, менее ограниченный режим.

Объяснение «EA разрушило геометрию внимания» правдоподобно, но не доказано. Альтернативы: неверный масштаб, шумная/плохо обусловленная ковариация, особенности нормировки, потеря полезных различий второго порядка. Нужны отдельные абляции.

4. Где вставлять калибратор

Текущий вычислительный путь:

X [208×T] → C [270×208] → Wu + bias [270×270]
          → Ws [25×270] → H: 25 временных фильтров → декодер → E [768×149]
          → сравнение с аудио → ранжирование кандидатов
Место Плюс Ограничение
До C, по исходным датчикам Можно использовать физическую геометрию 208 каналов; преобразование меняет смысл сенсорной раскладки
До W_s, в 270 каналах Ещё нет сжатия до 25 ветвей Много коэффициентов для короткой калибровки
После W_s, до H Всего 25 измерений; удобно для Procrustes Потерянную при W_s информацию уже не восстановить
После декодера, по E Вся сеть фиксирована, есть аудио-цель Высокая размерность; нельзя произвольно терять временную структуру
По матрице сходств Очень дёшево, не вмешивается в сеть Может улучшать поиск, не устраняя физиологический сдвиг

В коде retrieval нормируется весь тензор 768×149, а не независимо каждый временной кадр. Следовательно, перенос метода из EEG-to-image с одним вектором на пробу требует отдельного решения о представлении. Простое усреднение времени меняет исходную задачу. Реализация сходства в зафиксированной версии LISA.

5. Семейство I: использовать то, что сеть уже умеет

5.1. Исправленный масштаб средней W_s

Гипотеза из твоих данных. Зафиксировать на dev множитель средней W_s или коэффициент усиления ветвей. Сравнить population-normalization и нормировку по бюджету. Полезно проверять масштаб активаций ветвей, а не только норму матрицы: одно не гарантирует другое из-за ковариации входов.

Преимущество — почти нулевая стоимость применения. Риск — компенсировать специфичный для одного протокола дефект. Глобальное положительное масштабирование уже готового embedding не изменит cosine ranking; воздействовать нужно до нелинейной части или неравномерно по признакам. Аналогично одна температура не улучшает Top-k сама по себе.

5.2. Выбор готовой субъектной матрицы

Предложение для LISA. На коротком известном аудио прогнать нового участника через все source-W_s одного checkpoint. Выбрать матрицу по retrieval-loss или рангу правильной пары среди отрицательных примеров. Затем зафиксировать выбор и применить к другим фрагментам.

Это не требует общей записи с source-людьми: нужно лишь знать target-аудио. Хороший результат будет означать, что часть индивидуальных преобразований взаимозаменяема. Выбирать следует только обученные source-слоты; heldout-слот в checkpoint случайный. На 30 сек есть лишь 10 трёхсекундных окон — выбор среди 26 вариантов может быть нестабилен.

5.3. Ансамбль предсказаний вместо средней матрицы

Для каждого source-W_s вычислить сходства с одним и тем же банком аудио, затем усреднить их. Начать с равных весов; далее — заранее ограниченный top-k или веса, вычисленные на calibration.

Из-за нелинейного декодера в общем случае:

decoder(mean(Ws) · U) ≠ mean(decoder(Ws · U)).

Поэтому существующий результат mean_Ws ничего не доказывает об ансамбле. Общие C и Wu можно вычислять один раз. Цена — несколько запусков H/decoder. Усреднять W_s из разных seed/checkpoint без согласования скрытых координат нельзя; предсказания в одном аудиопространстве объединять проще.

5.4. AdaBN: калибровка внутренних статистик

AdaBN заменяет статистики BatchNorm на статистики нового домена без градиентного обновления весов. Исходное доказательство относится к computer vision, не к МЭГ. Li et al., 2016.

Применение к LISA — гипотеза. BN реально есть в ConvBlock и ConvHead, а exp06 сохранял его статистики. Оценить моменты на отдельной неразмеченной калибровке, смешать source/target raw moments с коэффициентом, выбранным на dev, затем зафиксировать. Для смешивания дисперсий нужно учитывать различие средних, а не только брать среднее двух variance.

Не переводить всю сеть в train(): это может включить dropout и другие механизмы. Короткая запись с артефактами или преобладанием тишины даёт плохие оценки. При строгом запрете менять любое состояние сети этот режим не подходит; при запрете target-backprop подходит.

6. Семейство II: статистическое и временное выравнивание

6.1. Диагональная нормировка, whitening и recoloring

EA приводит ковариацию сигналов к единичной и не требует target labels. Первичная работа проверяла EEG motor imagery и ERP, а не LISA speech retrieval. He & Wu, 2020; препринт 2018.

В FQW нужно сначала сравнить минимальные изменения: общий gain, диагональное масштабирование, затем регуляризованное преобразование к source-reference, а не обязательно к единичной ковариации. Возможная форма:

A = R_reference^(1/2) · R_target^(-1/2).

Это только согласование вторых моментов. Даже при точных ковариациях произвольная ортогональная Q даёт целое семейство решений:

A(Q) = R_reference^(1/2) · Q · R_target^(-1/2).

Следовательно, одинаковая ковариация не определяет, где находится речевой компонент. Общий стимул или геометрия могут помочь определить оставшуюся неоднозначность. Для коротких записей обязательны shrinkage и ограничение обусловленности; место преобразования нужно проверять отдельно.

6.2. Римановские методы — не готовая замена слоя LISA

Riemannian Procrustes работает с SPD-признаками и согласует распределения ковариаций; это не то же самое, что обычный Procrustes временных сигналов. Его варианты имеют разные требования к соответствиям/меткам. Rodrigues et al., 2019.

GOPSA совместно оценивает доменную рецентрацию и регрессионную модель на ковариационных признаках; основная проверка — прогноз возраста по resting-state EEG разных центров. Это интересный фон, но не готовый калибратор для замороженной LISA. Mellot et al., NeurIPS 2024.

Приоритет: после дешёвых контролей, а не первая новая ветка. Отрицательный EA не опровергает всё семейство, но требует более точной гипотезы, чем «другая метрика должна помочь».

6.3. Индивидуальная задержка ответа

В exp06 МЭГ уже сдвинут относительно аудио на 150 мс. Можно на известном calibration-аудио выбрать небольшую поправку вокруг этого значения, затем зафиксировать её. Лаг подбирать по качеству retrieval с отрицательными кандидатами, не по test.

Поддержка идеи моделировать стимул–ответ во времени есть в TRF-подходах; эффективность именно индивидуальной поправки LISA остаётся гипотезой. Crosse et al., mTRF, 2016.

Нельзя использовать циклический сдвиг массива, перенося конец окна в начало. Нужны исходные временные поля либо единая обрезка с корректными границами. Сначала исключить техническую ошибку синхронизации, затем интерпретировать разницу физиологически.

7. Семейство III: известный или общий аудиостимул

7.1. Procrustes к фиксированному эталону ветвей

Общий стимул даёт временные соответствия между людьми. В пределах одного LOSO-checkpoint построить эталон 25-мерных ответов source-участников на calibration-отрывок. Target обработать с зафиксированной исходной W_s. Центрированные ответы обозначим Z (target) и V (reference), оба 25×N.

Внешняя матрица Q решает:

min ||QZ − V||², при QᵀQ = I.

Это SVD-задача, без backprop. Возможны identity-regularization и отдельная коррекция масштаба. Идея соответствует семейству functional alignment; hyperalignment через согласованные стимулы изначально показан на fMRI. Это методический прецедент, а не доказательство для МЭГ-речи. Haxby et al., 2011.

Предложение для FQW: сначала scalar/diagonal baseline, затем Q25, затем регуляризованная полная матрица. Не начинать с 208×208. Построить эталон на calibration-стимуле, который совпадает по audio_id и времени, исключая target из усреднения. Mean-template может подавлять индивидуальный сигнал, поэтому сравнить с несколькими надёжными source-эталонами.

7.2. Ridge и геометрический prior

Более гибкая матрица A допускает изменение масштаба и неортогональное смешивание. При предварительном центрировании:

min_A ||AZ − V||² + λ||A − A0||²
A = (VZᵀ + λA0) · (ZZᵀ + λI)^(-1).

Практически решать линейную систему, не вычислять inverse явно. A0 может быть identity или геометрически предложенным преобразованием. Гипотеза: на короткой записи prior уменьшает нестабильность. Это предлагаемая комбинация, её новизна не установлена.

Прецедент межсубъектного предсказания МЭГ через ridge есть у Ravishankar et al.; задача — naturalistic reading, не прослушивание речи. Single-Trial MEG Data Can Be Denoised Through Cross-Subject Predictive Modeling, 2021.

Если вместо внешней A аналитически вычислять новую W_s, это тоже допустимо в режиме «без градиентов», но уже не в строгом режиме «веса LISA неизменны». Такой вариант следует сравнивать отдельно.

7.3. MCCA, CorrCA и SRM

Это способы находить согласованную часть ответов, а не знать заранее всю мозговую активность.

  • MCCA: разные проекции для разных людей. Есть прямая работа по MEG alignment Zhang et al., 2017 и работа 2023 с переносом на ранее не встречавшегося участника в grasping-задаче Inter-individual single-trial classification of MEG data using M-CCA.
  • Multiway CCA для непрерывных стимулов: авторы рассматривают извлечение общих ответов при различиях сенсорной/источниковой геометрии; это особенно близко к идее общего рассказа. de Cheveigné et al., 2019.
  • CorrCA: ищет воспроизводимые компоненты с дополнительными ограничениями на проекции. Не следует автоматически отождествлять его с MCCA или считать одинаковые веса оптимальными для голов разной геометрии. Parra, Haufe & Dmochowski, 2019.
  • SRM: общее низкоразмерное временное представление и индивидуальные отображения. Основной первоисточник относится к fMRI и предполагает оценку модели общего ответа. Chen et al., NeurIPS 2015.

Ключевое ограничение совместимости: новая ось MCCA/SRM не является осью, которую ожидает замороженный LISA-decoder. Нужно либо отображать в уже фиксированные ветви конкретного checkpoint, либо обучать исходный decoder в новом пространстве на source-людях. Последнее — отдельный source-training эксперимент.

Вращение перед и после временных фильтров не взаимозаменяемо: разные h_k обычно дают H(ω)A ≠ AH(ω). Нельзя переносить A через временной слой без проверки. Если начальная W_s уже отбросила полезный компонент, калибратор 25×25 его не восстановит; тогда нужна коррекция раньше или вычисление новой проекции 270→25.

7.4. Предсказанный эталон вместо одинаковой записи

Если source-люди не слушали точно такой же отрывок, можно заранее на них оценить encoding-модель: аудиопризнаки → ожидаемая часть МЭГ/ветвей. На новом calibration-аудио она создаст предсказанный эталон. TRF задаёт связь непрерывного стимула и ответа с временными лагами. Официальный mTRF Toolbox.

Предложение: сначала низкоразмерные акустические признаки и устойчивые source-ветви; проверить предсказуемость эталона на source-validation до любой target-калибровки. Ошибочный шаблон навязывает модели ложное соответствие. Этот путь требует source-side оценки дополнительной модели и сложнее прямого общего стимула.

CCA между речью и EEG также имеет отдельный первичный прецедент; он поддерживает поиск согласованных стимул–ответ компонентов, но не гарантирует перенос LISA. Decoding the auditory brain with canonical component analysis, 2018.

7.5. Повторение и выбор калибровочного материала

Несколько повторений одного отрывка помогают оценить воспроизводимую часть ответа; несколько разных отрывков лучше покрывают разнообразие речи. Это trade-off, а не установленный оптимум. DSS использует baseline и biased covariance, например ковариацию воспроизводимого ответа, для выделения компонент. Документация DSS с первоисточниками.

Для FQW сначала оценить на source-людях, какие доступные фрагменты дают устойчивые ответы и хорошую обусловленность калибровки. Выбирать запись по test-результатам нового человека нельзя. Тоны/щелчки могут уточнить грубые слуховые ответы и задержку, но калибровка на них не обязана переноситься на признаки естественной речи. Нужна отдельная проверка; существующий набор рассказов — более доступный старт.

8. Семейство IV: геометрия головы и физическая модель

8.1. Что дают HSP и ELP

HSP — поверхность головы; ELP — ориентиры/точки локализации; markers и метаданные прибора связывают голову с сенсорами. Размер, форма, положение и ориентация — разные величины. Сначала нужно согласовать единицы и системы координат. Облако поверхности не является картой извилин или полной forward-моделью.

В MNE можно оценивать rigid coregistration и масштаб surrogate-анатомии по fiducials/HSP. MNE Coregistration. Это позволяет начать геометрическую модель без индивидуального MRI, но не устраняет анатомическую неопределённость.

Аудит MRI пока не закрыт. Описание MEG-MASC, поле mri локального participants.tsv и число пригодных реконструкций в LISA описывают разные уровни доступности. Статья LISA упоминает шесть участников, чьи defaced MRI прошли реконструкцию поверхности. Нельзя обещать индивидуальные корковые модели для всех 27 только по наличию HSP. MEG-MASC, LISA, ограничения.

8.2. Выбор W_s по геометрии

Низкая стоимость, гипотеза. Описать участников шириной/длиной/формой головы, положением относительно шлема и, при возможности, расстояниями до датчиков. Искать близких source-людей внутри LOSO и выбирать/взвешивать их готовые матрицы.

Сначала проверить, связана ли геометрическая близость с качеством переноса конкретной W_s. Сравнить с выбором случайного донора, медианного донора и донора по статистикам сигнала. Корреляцию расстояния голов с расстоянием сырых весов нельзя считать достаточным доказательством полезности.

8.3. Пересчёт к общей сенсорной геометрии

Идея: оценить скрытые источники из target-измерений и снова спроецировать их на reference-прибор/голову:

X_reference ≈ L_reference · J_target · X_target,

где J_target — регуляризованный inverse, а L_reference — forward для согласованного пространства источников. При разных анатомиях нужен ещё оператор соответствия источников, иначе произведение не имеет физически корректного смысла.

Риски: неточность coregistration/анатомии, усиление шума inverse-решением, сглаживание, несовпадение с preprocessing, на котором обучена LISA. Сфера или масштабированный шаблон — приближение, которое сначала нужно проверить на синтетических данных с известной геометрией.

Полный переход к source-space может быть хорошей новой архитектурой, но нельзя просто подать корковые источники вместо 208 датчиков в существующий checkpoint. Для совместимости нужен обратный forward к ожидаемым каналам либо новая source-side тренировка.

8.4. Почему spherical attention не равно SSS

У внимания LISA гармоники задают веса смешивания датчиков по углам. Радиус в его вычислении не используется. SSS описывает физическое магнитное поле, включая различие внутренних и внешних источников. Совпадение слова «гармоники» не делает эти методы взаимозаменяемыми. Taulu, Kajola & Simola, 2004.

SSS и перенос к общей геометрии перспективны, но MNE прямо называет применение Maxwell filtering к non-Neuromag экспериментальным. У MEG-MASC KIT/Yokogawa. Нельзя считать Elekta MaxFilter готовой стандартной процедурой для этих данных. MNE: SSS/Maxwell filtering.

9. Семейство V: калибровка выходов и поиска

9.1. Поправка embedding по известному аудио

Сеть фиксирована; её выход E сопоставляется с известным аудио A внешней диагональной, ортогональной или ridge-картой. Это supervised fitting калибратора, хотя backprop по сети отсутствует.

Начинать с небольшой размерности/identity prior. Полная карта по flattened embedding 768×149 практически неприемлема на короткой записи. Возможная гипотеза — общая коррекция по feature-оси в каждом временном кадре с сохранением временной сетки. PCA-базис и его размер фиксировать на source/dev; target-кадры коррелированы и не являются тысячами независимых обучающих примеров.

9.2. CSLS и SATTC: исправление «слишком популярных» кандидатов

Некоторые аудиоэмбеддинги могут оказываться близки слишком многим МЭГ-запросам. Коррекция локальной плотности/популярности меняет ранжирование. SATTC сочетает статистическую нормировку EEG embeddings, CSLS и структурные признаки сходства при замороженных энкодерах. Работа относится к EEG-to-image. Huang & Zhu, 2026.

Для LISA сначала измерить hubness и проверить простой CSLS-компонент. Отдельно фиксировать, используются ли только calibration-запросы для статистик или весь test-batch: второе — трансдуктивный режим, а не перенос заранее рассчитанной карты на будущие записи. Галерея кандидатов сама по себе не является утечкой для retrieval, но скрытые соответствия и принудительное «каждый кандидат встречается ровно один раз» меняют постановку.

9.3. SCORE: восстановление координат без target labels

SCORE оценивает карту по надёжным предполагаемым соответствиям brain–image с исправлением hubness и ортогональным преобразованием. Полная система включает recovery-aware source-training, но авторы отдельно проверили recovery-модуль поверх обычных замороженных checkpoint. Поэтому этот модуль можно рассматривать отдельно от переобучения общей модели. Это свежий препринт по EEG-to-image, не подтверждение для MEG speech. Cui et al., 2026, таблицы 2–3.

Риск для FQW: если исходный перенос слаб, ошибочные псевдопары закрепляют неверную карту. При наличии настоящего calibration-аудио сначала использовать реальные пары — это проще и надёжнее для диагностики. Переход к label-free следует делать после доказательства, что пространство вообще поддаётся такому выравниванию.

Улучшение retrieval после CSLS/SCORE не является доказательством улучшенной локализации источников или семантического декодирования.

10. Если можно менять обучение на source-людях

Это другой бюджет работ, но он совместим с конечной целью «новому человеку не требуется дообучение».

  1. Эпизодическая подготовка к калибровке: во время source-training имитировать нового участника, вычислять тот же будущий аналитический калибратор и обучать общую сеть быть совместимой с ним. Recovery-aware часть SCORE даёт смежный прецедент.
  2. Геометрическая условная модель: заранее учить отображение head-geometry → W_s. На новом человеке только inference. Это отдельная модель и требует многих source-людей; 27 участников могут ограничивать её сложность.
  3. Общее пространство источников/ответов: сначала физическое или функциональное согласование всех source-людей, затем обучение общего decoder именно на таком входе.
  4. Аугментации геометрии, масштаба и шума: обучать устойчивость к допустимым изменениям, не разрушая речевой ответ. Простое вращение картинки датчиков не обязательно физически корректно для МЭГ.

Эти варианты не нужно смешивать в одной таблице с калибраторами существующего checkpoint: улучшение может происходить из-за нового source-training. Для ВКР их разумно оставить расширением после основной серии.

12. План исследования, который можно зарегистрировать до новых результатов

Этап 0. Данные, baseline и воспроизводимость

Вернуть отсутствующие массивы LOSO или определить серверный путь их хранения; ничего не переучивать ради их копирования. Проверить channel order, audio_id, время событий и хеши протокола. Восстановить работающую среду для MNE отдельно от изменения научных гипотез.

На dev-людях выбрать исправленный gain-baseline. Сохранить исходный mean_Ws для сопоставимости. Одинаковая нормировка и одинаковые окна у всех методов одной группы. Zero-data, unlabeled calibration и known-audio calibration — разные линии сравнения.

Этап 1. Дешёвые методы на готовых checkpoint

Сравнить: исходный baseline; gain-baseline; равный ensemble; выбор одной source-W_s; AdaBN. Не комбинировать всё сразу. Для выбора слотов использовать только calibration-отрывок; score оценивать с отрицательными аудио. Отдельный oracle по test допустим лишь как явно обозначенная диагностическая верхняя граница, никогда как deployable результат.

Этап 2. Общий стимул — основной опыт

  1. Эталон source-ответов построить только по выбранному calibration-стимулу и без heldout.
  2. Зафиксировать baseline-W_s, место внешней карты и пространство reference.
  3. Сравнить identity, scalar, diagonal, Procrustes25, ridge25.
  4. Проверить качество на другом временном фрагменте и, затем, на другой истории.
  5. Если улучшилась корреляция с template, но не retrieval, считать это отрицательным результатом для цели декодирования.
  6. Если 25-мерная карта не помогает, проверить информацию до W_s или аналитическую новую W_s отдельным режимом.

Этап 3. Геометрия как prior

Сначала получить таблицу geometry coverage и качество coregistration. Проверить связь geometry-distance с переносимостью W_s на dev. Сравнить: identity prior, geometry prior, functional only, geometry + functional. Плохой prior должен иметь возможность ослабляться регуляризацией, а не принудительно определять ответ.

Этап 4. Калибровка поиска

На сохранённых выходах проверить hubness, простой CSLS и known-pair output alignment. Лишь затем label-free recovery. Отдельно показать результаты при 99 кандидатах и при более крупном фиксированном банке, если он подготовлен без нарушения split. Не приписывать прирост от gallery-postprocessing улучшению мозговых представлений.

Этап 5. Подтверждение на новом материале

Текущий test уже использовался для диагностики и обсуждения гипотез. Новые сравнения на нём полезны как продолжение разработки, но сильный итог требует свежей истории/сессии либо заранее закрытого нового набора. «Новая история для target» и «новая история для всех source и target» — разные проверки, их нужно назвать явно.

13. Протокол, который не преувеличивает результат

Бюджеты: сохранить 0/30/60/120/300/600/882 с для сопоставимости, но отдельно учитывать время подготовки геометрии, ICA и вычислений. Наличие 3000 отсчётов в 30 сек не означает 3000 независимых наблюдений.

Непрерывность: текущий sampler выбирает последовательные окна из отсортированного train-пула; такой блок может пересечь границу аудиофайла/задачи. Для заявления «непрерывная минутная калибровка» выбирать блок внутри одного физически непрерывного фрагмента. Сумма длительностей окон и elapsed recording time — разные бюджеты.

ICA: pipeline применяет готовые индивидуальные ICA-решения к записи. Если они оценены по полной target-сессии, это дополнительная неразмеченная информация за пределами 30 сек. Нужно проверить provenance и отдельно обозначить «30 сек для калибратора после доступной ICA» и «весь deployment ограничен 30 сек». Это не обязательно утечка меток, но различие протоколов.

Гиперпараметры: rank, lambda, число соседей, сила BN-смешивания, правило выбора source и набор lag — только dev/validation. Не выбирать метод заново для каждого test-человека по его test-качеству.

Статистика: усреднять повторы и seed внутри человека, затем оценивать парные различия между методами по людям. Не выдавать 72 subject×seed за 72 независимых человека. Помимо среднего — медиана, доля улучшившихся участников, худший квартиль, доверительный интервал эффекта. Для семейства сравнений заранее выбрать поправку и основные endpoints.

Метрики: Top-1, Top-10, mean rank, время калибровки/инференса, устойчивость выбора W_s/Q/лага между повторениями. Для геометрии — ошибка coregistration. Для functional alignment — корреляция на невиденном отрывке как дополнительная, но не основная метрика.

Отсутствие target-backprop: для воспроизводимости логировать неизменность neural parameters, список изменённых buffers/внешних матриц и хеш исходного checkpoint. Это проверяет обещанный режим, а не является отдельной мерой качества.

Интерпретация: после входного или branch-преобразования пересчитать эффективный пространственный фильтр и паттерны. Корреляция attention maps сама по себе не доказывает сохранение источников. Если смешаны ветви с разными временными ядрами после H, исходная простая интерпретация «одна пространственно-временная ветвь» меняется.

14. Какую гипотезу защищать в ВКР

Предлагаемая основная формулировка:

Можно ли заменить градиентную адаптацию МЭГ-декодера речи короткой калибровкой, которая согласует ответы нового участника с фиксированным пространством обученной модели?

Три проверяемые гипотезы:

  • H1: часть потери переноса объясняется масштабом и статистиками, а не необходимостью учить новую сложную функцию. Проверка: gain и AdaBN.
  • H2: ответы на общий стимул позволяют вычислить устойчивую малую карту, улучшающую retrieval на другом материале. Проверка: diagonal → Procrustes → ridge с контролем бюджета.
  • H3: геометрия головы уменьшает объём функциональной калибровки. Проверка: geometry prior против identity при одинаковых окнах и методе.

Заранее не утверждать «впервые применён EA/MCCA к МЭГ»: соответствующие направления уже существуют. Потенциальный вклад — конкретная совместимость с интерпретируемой LISA, честная оценка небольшого бюджета и разбор того, какие виды индивидуальных различий исправляются без target-finetuning.

Слабый результат тоже содержателен: например, если геометрия объясняет мало, а functional calibration помогает, это ограничивает геометрическую гипотезу. Если ансамбль решает значительную часть проблемы, сложный калибратор должен превосходить именно его. Если ни один внешний метод не достигает ft_Ws, можно количественно показать цену запрета дообучения.

Числа из разных работ намеренно не сведены в общий leaderboard: модальности, задачи, число кандидатов и протоколы существенно различаются.

16. Итоговые артефакты и границы этого обзора

Подготовлены карта подходов, связь с существующими экспериментами, приоритеты и проверяемый протокол. Новые модели не обучались, сырые данные не скачивались, серверные эксперименты не запускались. Полные тексты и методические страницы использовались для ключевых направлений; для части смежных работ выводы ограничены доступными abstract/method summaries. Эффективность предложенных комбинаций на FQW ещё предстоит измерить.

Для первого нового исследования рекомендована компактная серия gain-baseline / ensemble / donor selection / AdaBN / Procrustes25, с исходным mean_Ws и имеющимся ft_Ws как ориентирами. Она отделяет масштаб, статистику, выбор готовой модели и собственно функциональное выравнивание; только после этого имеет смысл вкладываться в более тяжёлую физическую реконструкцию.

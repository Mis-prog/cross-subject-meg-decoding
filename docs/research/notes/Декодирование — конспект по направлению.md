# Декодирование мозг → текст/картинка — конспект по направлению

Рабочая шпаргалка по направлению 3 (реконструкция текста/изображений из МЭГ/ЭЭГ/фМРТ). Что за технологии, зачем, как связаны, какие задачи можно взять в ВКР. Держать под рукой на созвоне с Семенковым.

---

## 1. О чём направление

Мозг → стимул. Человек слушает/читает/смотрит, аппарат пишет сигнал, модель угадывает стимул. Три уровня выхода по сложности:

- **Классификация** — какая из N картинок/слов (проще всего).
- **Retrieval** — найти правильный стимул среди кандидатов (то, что делают почти все; метрика — top-1/top-10).
- **Генерация** — реально нарисовать картинку / породить текст (сложнее всего; диффузия/LM).

Приборы: **МЭГ** (дорого, чисто), **ЭЭГ** (дёшево, грязно, клинично), **фМРТ** (точно по месту, медленно по времени).

---

## 2. Эволюция архитектур (главная линия)

Всё направление — это история про **пространственный фильтр** (как смешать датчики, чтобы «услышать» нужную зону мозга):

| Метод | Пространственный фильтр | Учёт разных людей | Интерпретируемость |
|---|---|---|---|
| **PCA** | направления макс. разброса | — | средняя |
| **CSP** | обобщённые собств. векторы (отношение Рэлея) | — | высокая, но линейно |
| **EEGNet** | depthwise-свёртка (**обучается**) | нет | средняя |
| **BrainModule** (Meta 2023) | spatial attention | **есть (subject-слой)** | низкая (чёрный ящик) |
| **+ Трансформер** (Meta 2025) | то же + контекст предложения | есть | низкая |
| **Семенков** (2026) | обучаемые фильтры через **сферические гармоники** | — | **высокая (можно прочитать зоны)** |

Две ветки «после BrainModule»: **в сторону качества** (трансформер, Meta) и **в сторону понимания** (Семенков). Мои ниши — во второй.

## 3. Стек технологий — Meta / d'Ascoli 2025 (декодирование слов)

*Towards decoding individual words from non-invasive brain recordings (Nature Communications).*

- **Энкодер мозга:** BrainModule (CNN) = пространственное внимание по датчикам + subject-слой + свёртки.
- **Пулинг времени:** single-head self-attention → один вектор слова.
- **Контекст:** трансформер сверху (16 слоёв, 16 голов, dim 1024, rotary-позиции; либа `x-transformers`). Не предобученная LM (чтобы не было утечки языка).
- **Таргет-эмбеддинги слов:** `t5-large` (средний слой), усреднение по под-токенам = «смысл слова».
- **Лоссы:** CLIP (контрастный softmax) + **D-SigLIP** (SigLIP с дедупликацией повторов слов).
- **Бейзлайны:** ridge-регрессия (`sklearn`), EEGNet, BrainModule отдельно.
- **Препроцессинг:** `MNE-Python`, полоса 0.1–40 Гц, ресемпл 50 Гц, `RobustScaler`, клип [−5,5].
- **Тайминги слов:** `WhisperX`. ⚠️ Момент начала слова считается ИЗВЕСТНЫМ (допущение).
- **Retrieval:** голый косинус, словарь 250 частых слов.
- **Обучение:** AdamW, lr 1e-4, batch 64, cosine-decay, early stopping, A100 40GB.
- **Данные:** МЭГ (Elekta 306) + ЭЭГ; MEG-MASC и др. 723 чел., 3 языка.
- **Зачем так:** масштаб + контекст ради КАЧЕСТВА. Результат: до 37% top-10 из 250; zero-shot слов; МЭГ+чтение > ЭЭГ+слушание.

## 4. Стек технологий — Семенков 2026 (интерпретируемое декодирование речи)

*Interpretable MEG Decoding of Perceived Speech (arXiv 2608.01481).*

- **Задача:** retrieval среди 1005 кандидатов, обучение в стиле CLIP.
- **Таргет-эмбеддинги:** **wav2vec 2.0** — АКУСТИЧЕСКИЕ (про звучание, не смысл).
- **Пространственные фильтры:** через **сферические гармоники** (гладкий узор на сфере датчиков); **K ветвей** (≈25) → компактно и читаемо.
- **Временные фильтры:** обучаемые (≈150 мс).
- **Чистка сигнала:** удаление глазных/сердечных артефактов.
- **Компактность:** декодер ~в 20× легче по параметрам, чем baseline.
- **Локализация источников:** `MNE-Python` (minimum-norm) — «где в мозге сидит сигнал».
- **Интерпретация:** occlusion-анализ признаков стимула → декодирование тянут АКУСТИКА (тишина, громкость, гласные, онсеты), а не смысл.
- **Бейзлайн:** пайплайн Défossez / `brainmagick`. Данные: MEG-MASC. Фреймворк: PyTorch + MNE.
- **Зачем так:** ради ПОНИМАНИЯ (что/где), а не гонки за accuracy.

## 5. Мини-глоссарий (что значит термин)

- **CLIP-обучение** — тянем правильную пару (мозг ↔ стимул) вместе, чужие врозь; потом ищем ближайшее.
- **Retrieval** — не расшифровка дословно, а поиск правильного стимула среди кандидатов.
- **wav2vec 2.0** — готовая модель, звук → вектор; кодирует ЗВУЧАНИЕ, не смысл.
- **t5-large эмбеддинг** — слово → вектор; кодирует СМЫСЛ.
- **subject-слой** — «ручка под каждого человека», гасит различия мозгов; помогает на знакомых, ломает zero-shot на новых.
- **Сферические гармоники** — язык гладких узоров на сфере (Фурье на шаре); задают лёгкий интерпретируемый пространственный фильтр.
- **Локализация источников** — восстановить, где в мозге сигнал (обратная задача, ill-posed).
- **Occlusion-анализ** — по очереди «затыкаем» признак стимула и смотрим, что сильнее роняет качество → что модель реально использует.

## 6. Открытые задачи (кандидаты ВКР)

1. **Реранжирование в retrieval** ⭐ — заменить голый косинус на реранкер + hard negatives. *Фит max, риск низкий (моя профессия).*
2. **Смысл или конфаунд** — развести, тянет ли декодер смысл или длину/частоту/часть речи/акустику. *Защитимо при любом ответе.*
3. **Акустика vs семантика + сдвиг зон** — сменить таргет (wav2vec→текст) и показать сдвиг источников. *Продолжение Семенкова.*
4. **Обобщаемость** — сколько минут нового человека нужно (few-shot, shared-subject как в MindEye2).
5. **МЭГ → ЭЭГ** — насколько падает качество на дешёвом ЭЭГ и как сократить разрыв.
6. **Границы слов / CTC** — убрать допущение «onset известен», детектить начало слова.

Ставка: **1 (+2 довеском)** — метод + анализ = цельный диплом.

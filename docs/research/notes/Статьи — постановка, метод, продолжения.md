Сводка по всем прочитанным работам: что за задача, как решают, и куда это можно продолжить (в т.ч. под ВКР). Составлено на основе полного чтения статей.

## Таблица 1. Основные прочитанные работы

| Работа | Постановка задачи | Метод решения | Возможные продолжения / смежные темы |
|---|---|---|---|
| **Семёнков и др., 2026** — Interpretable MEG Decoding of Perceived Speech (arXiv 2608.01481) | По неинвазивному МЭГ находить услышанный 3-сек фрагмент речи среди 1005 кандидатов (retrieval). Главное — не точность, а **интерпретируемость**: понять, ГДЕ в мозге и на КАКИЕ признаки опирается декодер. | Интерпретируемый фронт-энд: пространственные фильтры через **сферические гармоники**, K=25 ветвей, обучаемые временные фильтры (150 мс), удаление глаз/сердца. Обучение в стиле **CLIP** против **wav2vec 2.0** (акустика). Локализация источников (MNE) + **occlusion-анализ** 19 признаков. Итог: 39.8% Top-1 / 70.4% Top-10, ~в 20× легче Meta. Вывод: декодируется **акустика, не смысл**. | • Заменить акустический таргет на **смысловой** и показать **сдвиг зон** акустика→семантика. • Расширить occlusion **семантическими** признаками (surprisal, часть речи). • **Реранжирование** вместо голого косинуса. • Разгадать «12 измерений» таргета. • Предобучить фронт-энд **self-supervised**, сохранив читаемость. |
| **Meta / d'Ascoli, 2025** — Towards decoding individual words (Nature Comms) | По МЭГ/ЭЭГ находить **отдельные слова** (retrieval), в т.ч. слова не из обучения (zero-shot). Масштаб: 723 чел., 3 языка. | CNN (**BrainModule**) + **subject-слой** + **трансформер** (контекст предложения). Таргет — **смысловые эмбеддинги** слов из t5-large. Лоссы: CLIP + **D-SigLIP** (дедуп). Оценка: top-10 из 250, защита от утечек через хеширование сплитов. Результат: до 37% top-10; МЭГ+чтение > ЭЭГ+слушание; «глубокие» данные > «широких». | • **LLM-сборка** связного текста из шумных слов (они сами предлагают). • **RAG для мозга** (retrieval + реранжирование). • Развести **смысл vs конфаунд** (длина, часть речи). • Убрать допущение «onset слова известен» (**CTC**). • **Обобщаемость** на новых людей. |
| **Scotti и др., 2024** — MindEye2 (ICML) | Восстановить **увиденную картинку** по фМРТ, обучаясь на новом человеке всего за **1 час** данных. | **Shared-subject alignment**: мозг всех людей линейно проецируют в общее латентное пространство → в CLIP-пространство картинок → диффузия рисует изображение. Есть retrieval-ветка. Дообучение на нового человека за 1 ч. | • Перенести приём **shared-subject** на **МЭГ-речь** (обобщаемость). • Few-shot адаптация к новому человеку. • Связка retrieval + diffusion для аудио/речи. |
| **Kleeva & Ossadtchi, 2025** — CD-PSIICOS (NeuroImage) | По МЭГ/ЭЭГ построить карту **функциональной связности** («кто с кем синхронен»), убрав **ложные связи** от растекания сигнала (spatial leakage). | Метод обработки сигналов (без обучения). Проектор, который давит «эхо», но сохраняет истинные нуль-фазовые связи; **взвешивают по реальной мощности источников** («context-dependent»). Проверка: симуляции (ground truth) + открытый МЭГ NIMH (9 чел.). Итог: оптимум на меньшем ранге (~40–100), выше ROC-AUC, устойчив к регуляризации. | • Поведение при **десинхронизации** сенсомоторных ритмов (движение/воображение) — авторы сами наметили. • Связность → **прогноз приступов** на открытых ЭЭГ. • ML поверх карт связности (GNN). • Связность как **биомаркер** эпилепсии. |
| **Ripart/Spitzer и др., 2025** — MELD Graph (JAMA Neurology) | Автоматически **найти и оконтурить очаг ФКД** (причина эпилепсии) на МРТ, в т.ч. «MRI-negative», с малым числом ложных срабатываний. | **Графовая нейросеть** (graph-based nnU-Net) на **поверхности коры**: 34 признака × 163 842 вершины, видит всё полушарие сразу. 1185 чел., 23 центра. Результат: PPV 67% против 39% у baseline; на независимой выборке 76% против 46%. Интерпретируемые отчёты. Код открыт. | • **Улучшить архитектуру** (attention/трансформер на поверхности). • **Перенос между сканерами/центрами** (domain shift) — та же тема обобщаемости. • **Self-supervised** предобучение на здоровых поверхностях. • Робастность к пропущенной модальности (нет FLAIR). |
| **Gill и др., 2021** — Multicenter DL for FCD (Neurology) | То же — детекция ФКД на МРТ; **сильный baseline** для сравнения. | Каскад CNN на 3D-патчах T1+FLAIR (CNN-1 находит → CNN-2 режет ложные) + **байесовская неопределённость** (MC-dropout) для ранжирования. 148 чел., 9 центров. Чувствительность 93% (85% MRI-negative), ~6 ложных/пациент. | • Служит **точкой отсчёта** для любых новых методов ФКД. • Сравнение «патчи vs поверхность/граф». • Калибровка уверенности. |

## Сводка: продолжения, сгруппированные по «твоим нишам»

- **LLM/RAG-угол (твоё уникальное преимущество):** LLM-сборка текста из шумных слов; RAG для мозга; ranking-лосс в самом обучении. → растёт из Meta d'Ascoli + Семёнкова.
- **Интерпретация (угол Семёнкова):** смысл vs акустика + сдвиг зон; occlusion с семантикой; что за «12 измерений». → растёт из препринта Семёнкова.
- **Обобщаемость (сквозная тема):** few-shot на новых людях (МЭГ-речь); перенос между центрами (ФКД); shared-subject из MindEye2. → общая боль всех работ.
- **Foundation-модель:** предобучить интерпретируемый фронт-энд self-supervised. → MEG-GPT + stLaBraM + Семёнков.
- **Эпилепсия (медицина):** прогноз приступов (time-series); связность → прогноз; детекция ФКД. → CD-PSIICOS + Future-Guided + MELD.

**Ставка под тебя:** реранжирование/LLM-угол (ВКР-1) как ядро + анализ «за счёт чего прирост» — метод и интерпретация в одном, на открытых данных.

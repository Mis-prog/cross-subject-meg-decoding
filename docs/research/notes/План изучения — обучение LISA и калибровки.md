## Часть 1. Как учится LISA (3–4 дня)

- [ ] **Прямой проход модели.** `src/lisa/model/nn_modules.py`:

  - `SpatialModule` (стр. 870–1175);
  - `LISA.forward` (стр. 1357–1373).
  - *Руками:* с помощью hooks проверить формы `[B,208,300] → [B,270,300] → [B,25,300] → [B,768,149]` и посчитать параметры по слоям. На одного человека должно быть 6 750.
- [ ] **Функция потерь.** `src/lisa/training/criteria.py`, стр. 11–112. Разобраться:
  - косинус считается по развёрнутому (feature×time) вектору;
  - повторяющиеся таргеты в батче склеиваются;
  - температура хранится как логарифм;
  - в обучение идёт `loss_temperature`.
  - *Вопрос для проверки:* при случайном угадывании CE ≈ ln N. В exp04 val loss 4.33 → 4.29 при ln 76 = 4.33, а Top-10 при этом 26%. Почему ранги улучшаются раньше, чем loss?

  - `evaluate` — стр. 217–364;
  - `fit` — стр. 420 и далее;
  - заморозка части сети — `switch_temporal_gradients`, стр. 204–216.
  - *Вопрос:* что станет со статистиками BatchNorm при калибровке без `model.eval()`?
- [ ] **Мини-опыты на данных exp04.**
  - Обучать только subject layer, всё остальное заморозить.

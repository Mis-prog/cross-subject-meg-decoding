# Презентация ВКР на 5 минут

Семь основных слайдов, литература и запасной слайд:

1. Тема — 20 секунд.
2. Задача: по МЭГ найти услышанный фрагмент речи; LISA и датасет MEG-MASC — 40 секунд.
3. Проблема (обоснование темы): индивидуальная матрица W_s, которой нет у нового человека; причины различий — 50 секунд.
4. Что уже сделано: подходы в литературе и пробел — 40 секунд.
5. Цель и три исследовательских вопроса — 55 секунд.
6. Сравниваемые способы настройки и протокол проверки — 50 секунд.
7. План работы и ожидаемый результат — 45 секунд.
8. Литература — вне основного выступления.
9. Запасной слайд: полная архитектура LISA — только для вопросов.

Предыдущие версии `slides.v1.md` … `slides.v9.md` и `style.v2.css` сохранены локально в `archive/` и исключены из Git. Схемы на слайдах 3 и 6 — `public/assets/lisa-subject-layer.svg` и `public/assets/expected-result.svg`; левый рисунок слайда 2 — фрагмент `meg-acquisition.png` (`meg-listener.png`).

`commission-short.pdf` — локальный экспорт для показа без установки программ, исключён из Git. `slides.md` — редактируемая презентация и заметки докладчика с таймингом. Источники находятся на слайдах и в заметках. Предварительные численные результаты не включены: реализация и протокол требуют валидации. Функциональное выравнивание представлено как одна из гипотез.

## Показ и редактирование

Из этой папки:

```sh
npm install
npm run dev
```

Открыть `http://localhost:3031`. Режим докладчика с заметками: `http://localhost:3031/presenter`.

## Сборка

```sh
npm run build
npm run export
```

Презентация использует Slidev. Если Chromium из Playwright не установлен, экспорт через имеющийся Chrome:

```sh
npm run export -- --executable-path "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

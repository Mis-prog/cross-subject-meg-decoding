# Цель и задачи

**Цель:** разработать калибратор, который получает индивидуальный слой LISA для нового участника без дообучения сети, по короткой записи, и сравнить его с дообучением.

**Задачи:**

1. Воспроизвести базовую модель и построить точки отсчёта для переноса на нового человека и новую сессию
2. Разработать калибратор без дообучения сети и сравнить его с существующими методами адаптации
3. Оценить обобщаемость и интерпретируемость калибратора, сформулировать рекомендации

**Ожидаемый результат:** калибратор, который настраивает модель на нового человека без дообучения, и оценка его качества относительно дообучения.

# Как отвечаю на вопросы

**Сравниваемые способы настройки** — от дешёвых к дорогим:

1. Средняя матрица обучающих участников, без данных нового человека
2. Выбор или смесь готовых матриц
3. Дообучение только $W_s$
4. Функциональное выравнивание по реакции на общий стимул
5. Дообучение всей сети, как ориентир сверху

**Проверка:** новый человек исключён из обучения общей модели, калибровка разной длительности, тест на отдельных данных. Для новой сессии $W_s$ из первой сессии проверяется на второй. Метрики Top-1 / Top-10.

50 секунд. Сравниваю пять вариантов — от самого дешёвого к самому дорогому. Средняя матрица вообще не требует данных нового человека. Выбор или смесь готовых матриц и дообучение только W_s требуют короткой калибровки. Функциональное выравнивание использует реакцию на общий стимул. Дообучение всей сети — ориентир сверху.
Проверка раздельная. Для нового человека: исключаю его из обучения общей модели, калибровка получает только отдельный фрагмент ограниченной длительности, качество измеряю на независимом тесте. Для новой сессии: матрица из первой сессии тестируется во второй — без адаптации и после неё.
Для всех методов фиксирую одинаковые тестовые окна, аудиокандидатов и бюджеты; гиперпараметры выбираю на валидации без итогового теста. Отдельно учитываю разброс между участниками и отделяю объём калибровки от данных для предобработки.
Top-1 / Top-10: правильный аудиофрагмент на первом месте / среди первых десяти кандидатов.
Источники: https://arxiv.org/abs/2608.01481 ; https://www.nature.com/articles/s42256-023-00714-5 . При одинаковых стимулах в разных сессиях для широких выводов нужен контроль переноса на новый аудиоматериал.

Каждый проект запускается из своей папки; команды приведены в его README. Основной редактируемый файл — `slides.md`, изображения — в `public/assets/`, компоненты графиков — в `components/`, если используются.

Предыдущие варианты короткой презентации сохранены локально в `2026-10-10_short/archive/` и исключены из Git. PDF и Word-материалы также остаются локально согласно `.gitignore`; экспорт может отражать другую редакцию, чем текущий `slides.md`.

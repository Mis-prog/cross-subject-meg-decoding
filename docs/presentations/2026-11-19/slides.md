# Как записывают МЭГ

Магнитоэнцефалография регистрирует слабые магнитные поля, которые возникают при электрической активности мозга.

<img class="meg-acquisition" src="/assets/meg-acquisition.png" alt="Участник слушает рассказ в наушниках. Датчики вокруг головы измеряют магнитные поля. Показания каждого датчика образуют временной ряд." />

# Поиск нужного отрывка, который слышал человек

По 3 секундам МЭГ ищем один услышанный отрывок среди кандидатов. Кандидаты это те отрывки которые человек слышал

<img class="retrieval-diagram" src="/assets/lisa-retrieval-ranked.png" alt="LISA переводит запись МЭГ в числовые признаки. wav2vec 2.0 строит признаки для каждого аудиоотрывка. Из трёх кандидатов для примера первым по сходству оказался отрывок номер два." />

# Проблемы

<img class="lisa-diagram" src="/assets/lisa-subject-layer.svg" alt="В LISA сигнал МЭГ проходит через общие слои и личную пространственную матрицу участника." />

У каждого участника из обучения своя матрица W<sub>s</sub>. Она переводит 270 пространственных признаков в 25 временных рядов. Остальные слои общие.

- **Тот же человек, другая сессия.** У людей мозг работает по разному исходя от сессии к сессии.
- **Новый участник.** Личной матрицы ещё нет. Чтобы её обучить, нужна отдельная запись для калибровки.

<!--

У нового участника матрицы ещё нет. Если обучать её отдельно для каждого человека, потребуется дополнительное время на калибровочную запись.

# Следующие эксперименты


| Дальше | Что меняем | С чем сравниваем |
| --- | --- | --- |
| **MoE** | Смешиваем две общие матрицы. Веса смеси определяем по неразмеченной записи. | Одна общая матрица и равная смесь двух матриц. |
| **ADAN** | При обучении уменьшаем информацию о сессии в признаках МЭГ. | Та же LISA без ADAN, тест на других сессиях. |

# Промежуточное выступление по ВКР · 19 ноября 2026

Десять слайдов примерно на пять–шесть минут. Оставшееся время отведено на вопросы. Текст выступления и источники находятся в заметках к слайдам в `slides.md`.

## Показ

Из этой папки выполнить `npm run dev`. Если зависимости ещё не установлены, сначала выполнить `npm ci`. Презентация открывается по адресу [localhost:3032](http://localhost:3032), режим докладчика доступен по [localhost:3032/presenter](http://localhost:3032/presenter).

`npm run build` создаёт статическую версию в `dist/`.

# Презентация ВКР для комиссии

10 основных слайдов на выступление около 10–11 минут и 4 запасных. Содержание основано на исследовательском обзоре, сохранённых результатах exp06 и итогах встречи с руководителем 5 октября 2026 года.

## Как открыть

- `commission-main.pdf` — только основной доклад, 10 слайдов.
- `commission.pdf` — полный комплект, включая запасные слайды.
- `speaker-notes.md` — текст выступления, пояснения к вопросам и источники.
- `slides.md` — редактируемый исходник Slidev. Графики хранятся в `components/`, точные значения — в `results.json`.

## Показ в браузере

Из этой папки:

```sh
npm install
npm run dev
```

Открыть `http://localhost:3030`. Для заметок докладчика использовать режим Presenter. Стрелки переключают слайды.

## Сборка и экспорт

```sh
npm run build
npm run export
npm run export:main
```

Для экспорта Slidev требуется `playwright-chromium`. При использовании установленного Chrome можно передать параметр `--executable-path` в команду экспорта.

## Источники данных

- `experiments/exp06_loso/results/summary.csv`: средние метрики и 95% интервалы.
- `experiments/exp06_loso/results/models.csv`: опорная joint-модель на оцениваемых участниках sub-04…sub-27.
- `experiments/exp06_loso/results/per_subject.csv` и `comparisons.csv`: парные сравнения.
- `docs/meetings/2026-10-05_semenkov_outcomes.md`: ближайший план.

Бюджет относится к калибровке после готовой ICA. Joint — модель с целевым участником в обучении. Эквивалентность адаптации Wₛ и joint в ±2 п.п. не установлена. Перенос между сессиями и авторское воспроизведение пока не выполнены.

Пакет `slide` по исходной ссылке является библиотекой управления выполнением JavaScript. Для презентации использован Slidev (`@slidev/cli`).

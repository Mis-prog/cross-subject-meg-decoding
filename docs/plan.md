## Открытые экспериментальные задачи

Источник задач ниже — [встреча 19 октября](meetings/2026-10-19_semenkov_outcomes.md).
На встрече не задавались обязательный порядок и срок завершения всего пакета.
Рабочая рекомендация для ближайшей итерации — начать с валидации на новых людях, чтобы следующие методы сравнивались по одной схеме.

| Задача | Статус | Что должно появиться для оценки выполнения |
|---|---|---|
| Вынести отдельных людей в validation exp09 | Не начато | Заранее зафиксированные train/val/test по людям; выбор checkpoint по validation со средней Wₛ; отдельная серия с новым протоколом |
| Показывать validation рядом с test | Не начато | Таблицы с обеими метриками и явным правилом выбора checkpoint/метода |
| Обучаемая общая (N+1)-я subject-матрица | Не начато | Протокол маршрутизации в индивидуальную или общую матрицу; подбор p по validation; сравнение с арифметической средней на том же разбиении |
| Euclidean / Riemannian alignment между сессиями, затем людьми | Не начато для полной серии | Отдельный протокол: источник ковариаций, доступ к целевым данным, референс и бюджет; сопоставимый baseline. Предварительный EA уже есть в exp06, но это другой опыт |
| Adversarial-голова по человеку или сессии | Не начато | Выбор оси сдвига и схемы обучения; коэффициент дополнительного loss выбирается на validation |
| Оценить применимость предобученных ЭЭГ/МЭГ-моделей | Не начато как отдельное сравнение | Краткий обзор, проверка типов датчиков и входов, затем спецификация сопоставимого эксперимента |
| Найти установившиеся методы функционального выравнивания | Есть предварительные материалы; обзор под новую серию не завершён | Несколько первичных работ, условия общих стимулов и выбранная схема проверки; [карта ресерча](research/README.md) |

## Как обновлять

После работы над задачей меняем статус и добавляем ссылку на конкретный результат: протокол, код, обзор или отчёт.
Запуск считается завершённым в оговорённом объёме; частичный результат сохраняет число выполненных фолдов/сидов.
Новые гипотезы сначала заносим в [исследования](research/README.md), а параметры запуска фиксируем в протоколе эксперимента до оценки test.
Исторические протоколы встреч и результаты старых серий не переписываем под новые условия.

# Глава 3. Межсубъектный перенос LISA без размеченной калибровки

## 3.1. Постановка эксперимента

В модели LISA индивидуальная матрица $W_s$ преобразует пространственное представление МЭГ участника $s$ из 270 каналов в 25 ветвей. Для участника, отложенного до тестирования, обученной индивидуальной матрицы нет. В эксперименте исследуется, повышает ли качество декодирования матрица, которую модель обучает совместно с индивидуальными матрицами, по сравнению с их арифметическим средним. Исходная архитектура описана в [главе 2](02_lisa_and_calibration.md) и [статье Семёнкова и соавторов](https://doi.org/10.1016/j.neuroimage.2026.122355).

**Средняя матрица.** На этапе обучения каждое окно МЭГ проходит через индивидуальную матрицу своего участника. При валидации и тестировании для всех отложенных участников используется одна матрица, полученная усреднением матриц 18 обучающих участников текущего фолда. Поправочный множитель равен единице.

$$
\overline W = \frac{1}{18}\sum_{s\in\mathcal S_{\mathrm{train}}} W_s.
$$

**Обучаемая общая матрица.** В слой добавляется матрица $W_{\mathrm{shared}}\in\mathbb{R}^{25\times270}$. На каждом прямом проходе для каждого окна независимо выбирается одна из двух матриц. Индивидуальная матрица используется с вероятностью 0,9, общая — с вероятностью 0,1. Общая матрица получает градиент через окна, прошедшие через неё. Остальные веса декодера оптимизируются совместно со слоем матриц. При валидации и тестировании для всех окон используется $W_{\mathrm{shared}}$ из выбранного чекпойнта. Оба варианта обучаются отдельно. [Реализация слоя](../../../code/scripts/exp10_shared_matrix/subject_layer.py)

## 3.2. Данные и протокол оценки

Для эксперимента использованы записи 27 участников MEG-MASC, слушавших четыре рассказа на английском языке. В выгрузку вошли 49 сессий. В пределах каждого фолда участники обучения, валидации и тестирования образуют три непересекающиеся группы, а обе доступные сессии человека относятся к одной выборке. Из шести заранее заданных групп текущая отводится под тест, следующая по кругу — под валидацию. Остальные четыре группы дают 18 обучающих участников. Валидационная и тестовая выборки содержат по 4 или 5 человек. Каждый участник один раз проходит тестирование и один раз используется для валидации. [Описание MEG-MASC](https://doi.org/10.1038/s41597-023-02752-5) · [Протокол разбиения](../../../experiments/exp12_paired_shared_matrix/protocol.json)

Аудио делится на выборки по целым частям рассказов. Состав фрагментов одинаков для всех фолдов и обеих моделей.

| Выборка | Аудиофрагменты | Аудиокандидаты при оценке |
|---|---|---:|
| Обучение | Три рассказа целиком и первые четыре части *The Black Willow* | — |
| Валидация | Пятая часть *The Black Willow* | 108 |
| Тест | Части с шестой по двенадцатую *The Black Willow* | 1005 |

В обоих вариантах используются AdamW, скорость обучения декодера $3\cdot10^{-4}$, размер пакета 100 и фиксированный сид 42. Все 12 моделей обучались по 20 эпох. Чекпойнт для каждого варианта и фолда выбирается по максимальному валидационному Top-10 с равным весом участников. При равном Top-10 выбирается чекпойнт с большим Top-1, при равенстве обеих метрик — чекпойнт более ранней эпохи. Тестовая оценка проводится после выбора чекпойнта. Бюджет размеченной калибровки составляет 0 окон, веса при тестировании фиксированы. Авторская поканальная нормировка использует статистики неразмеченной целевой записи. [Настройки и схема запуска](../../../experiments/exp12_paired_shared_matrix/README.md)

Для каждого окна МЭГ оценивается косинусное сходство выхода декодера с каждым аудиокандидатом. Ранг правильного кандидата равен числу кандидатов со строго большим сходством. При таком отсчёте Top-1 соответствует рангу 0, а Top-10 — рангу меньше 10. Метрики сначала рассчитываются по окнам всех доступных сессий одного участника, затем усредняются по участникам с равным весом. Для сравнения Top-10 берётся разность двух оценок на одних и тех же окнах каждого человека. [Реализация ранжирования](../../../code/scripts/exp10_shared_matrix/run_experiment.py)

## 3.3. Результаты

Обе модели оценены на каждом из шести фолдов. Для каждого варианта тестовая оценка охватывает 27 участников и 49 245 окон МЭГ. Обучаемая общая матрица повысила средний тестовый Top-10 с 34,11% до 35,41%, то есть на 1,30 процентного пункта. Top-1 вырос на 0,68 процентного пункта, а средний ранг правильного кандидата снизился на 5,07 позиции.

| Вариант | Валидация, Top-10 (108 кандидатов) | Тест, Top-1 (1005 кандидатов) | Тест, Top-10 (1005 кандидатов) | Тест, средний ранг |
|---|---:|---:|---:|---:|
| Средняя матрица | 72,67% | 12,27% | 34,11% | 108,55 |
| Обучаемая общая матрица | 75,33% | 12,95% | 35,41% | 103,47 |

Выигрыш по тестовому Top-10 наблюдался у 15 участников, снижение — у 11, у одного результат совпал. Медианная разность составила +0,25 процентного пункта. Средняя разность по фолдам варьировалась от −3,96 до +4,73 процентного пункта.

| Фолд | Тестовых участников | Top-10, средняя матрица | Top-10, обучаемая общая матрица | Разность, п.п. |
|---:|---:|---:|---:|---:|
| 0 | 5 | 33,00% | 34,56% | +1,55 |
| 1 | 4 | 29,93% | 34,65% | +4,73 |
| 2 | 5 | 40,97% | 44,27% | +3,30 |
| 3 | 4 | 34,17% | 31,98% | −2,19 |
| 4 | 5 | 31,74% | 35,02% | +3,28 |
| 5 | 4 | 34,00% | 30,05% | −3,96 |

Разности рассчитаны до округления. Двусторонний критерий Уилкоксона для парных разностей Top-10 дал $p=0{,}20$. Эта оценка носит разведочный характер, поскольку несколько участников в каждом фолде оцениваются одной моделью, а обучающие выборки разных фолдов пересекаются. Устойчивость наблюдаемого выигрыша к случайной инициализации и выбору вероятности маршрутизации остаётся открытым вопросом.

## 3.4. Выводы и ограничения

В заданном протоколе обе схемы позволяют использовать LISA для поиска аудиофрагментов по МЭГ новых участников с нулевым бюджетом размеченной калибровки. Для обучаемой общей матрицы средний тестовый Top-10 оказался выше на 1,30 процентного пункта при положительной разности в четырёх из шести фолдов. Эксперимент оценивает схемы обучения и применения слоя целиком, поскольку маршрутизация при обучении влияет также на общие веса декодера.

Вывод относится к отложенным частям рассказа, другие части которого входят в обучение. Нормировка использует неразмеченную МЭГ новых участников. Для точного описания предобработки применение ICA к архиву МЭГ требует подтверждения по журналу его подготовки. [Сведения о входных данных](../../../experiments/exp12_paired_shared_matrix/README.md)

Парная сводка воспроизводится командой `summarize` при указании каталога этой серии. [Скрипт эксперимента](../../../experiments/exp12_paired_shared_matrix/scripts/run_experiment.py)
